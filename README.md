# ZENIN INVEST

Prototype web responsive d'une plateforme multi-projets, avec interface en français et montants en FCFA.

## Fonctions
- Inscription et connexion de démonstration
- Catalogue de projets agriculture, énergie, immobilier et technologie
- Tableau de bord et portefeuille
- Dépôts, retraits et investissements fictifs
- Historique des opérations
- Administration locale et ajout de projets
- Interface adaptée aux mobiles

## Lancement
Ouvrir `index.html` dans un navigateur. Aucune compilation nécessaire.

## Sécurité et limites
Ce dépôt contient un prototype front-end uniquement. Les données sont conservées dans le navigateur (localStorage), les mots de passe de démonstration ne sont pas hachés et il n'existe ni serveur, ni base de données partagée, ni intégration de paiement. Ne pas utiliser avec de vrais clients, de vrais identifiants ou de l'argent réel. Les montants et rendements ne constituent pas une offre financière.

Avant tout lancement réel : construire une API sécurisée, stocker les mots de passe avec un hachage robuste, valider les autorisations côté serveur, connecter un prestataire de paiement agréé, prévoir les contrôles antifraude et la journalisation, puis vérifier les obligations réglementaires applicables au Burkina Faso et dans l'UEMOA. Aucun rendement ne doit être présenté comme garanti.
